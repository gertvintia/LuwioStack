"@luwio/cli": minor
---

Add `@luwio/cli`: the `luwio` command to scaffold a boilerplate Luwio app. `luwio create <dir>` generates a locale-routed React app (`@luwio/router` + `@luwio/locale` + `@luwio/translations`, Vite + TanStack Router) with a home page and a language switcher. Dependency-free (Node built-ins only).
